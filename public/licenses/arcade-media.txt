MODIFICATIONS / REPRODUCIBILITY
GIFs are fitted within 512 pixels without upscaling, preserving aspect ratio
to the nearest even pixel, with nearest-neighbor filtering. Outputs are
20 fps H.264 Baseline / yuv420p MP4, silent, with fast-start metadata.
Posters are PNGs extracted from each video's middle decoded frame.
No unrelated footage is downloaded.
Pong alone receives the monochrome threshold treatment described above.
Its conversion version, exact filter chain, threshold and SHA-256 conversion
fingerprint are recorded separately in the manifest, so changing this treatment
invalidates Pong's cached conversion without changing the other two clips.

Prepare: node scripts/prepare-arcade-media.mjs
Rebuild without network: node scripts/prepare-arcade-media.mjs --offline --force
Validate/reuse cache without network: node scripts/prepare-arcade-media.mjs --offline
FFMPEG_PATH and FFPROBE_PATH override /opt/homebrew/bin/ffmpeg and ffprobe.
Requires Node.js 22+ and FFmpeg with libx264; no npm dependencies are added.
Online reruns use conditional HTTP validators when available and SHA-256
comparison otherwise. Offline runs verify cached source hashes. Encoding
settings and tool versions are recorded; byte-identical regeneration requires
the same FFmpeg/libx264 build and platform.

Every source must have a GIF signature, multiple frames, positive duration
and a successful full FFmpeg decode. Both staged outputs must fully decode
before publication. Fully black decoded video frames are rejected. The
manifest is published only after all three media entries succeed.
For Pong, every decoded frame must also have neutral U/V chroma (128).

public/assets/arcade/manifest.json records source URLs, license/rights,
SHA-256 hashes, bytes, source dimensions/frame count/duration, video stream
metadata, poster dimensions/frame timestamp, and preparation settings.
assets/arcade/source/*.source.json records source cache hashes/metadata and
HTTP ETag/Last-Modified validators. Source GIFs remain outside public/.
No browser-decoding or Babylon runtime verification is claimed by this record.
